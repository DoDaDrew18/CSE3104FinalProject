## A Few Notes

**why saturated fat for scoring** — we picked sat fat as the single scoring metric because it's the most consistently reported nutrient across all four chain datasets and it's a widely accepted proxy for diet quality.

**why Tier 1 / Tier 2** — with only 4 chains, we split them by median sat fat into two tiers (lower = Tier 1, higher = Tier 2) instead of three. Tier 1 chains are McDonald's and Burger King; Tier 2 are Wendy's and Carl's Jr.

**why density instead of raw counts** — a zip with 100k people will always have more stores. density (per 10,000 residents) makes different-sized zips comparable.

**why a sklearn pipeline** — SimpleImputer + StandardScaler + LinearRegression. imputing with median handles missing demographic values; scaling puts all features on the same scale so coefficients are comparable.

## One File to Download Manually

`data/ACSDP5Y2024.DP05-Data.csv` is ~82MB and is not tracked in this repo.

to get it:
1. go to https://data.census.gov
2. search "DP05" — select **ACS Demographic and Housing Estimates**
3. set geography to **Zip Code Tabulation Area**, year to **2024 (5-year)**
4. download and save as `data/ACSDP5Y2024.DP05-Data.csv`

everything else in `data/` is already in the repo.
